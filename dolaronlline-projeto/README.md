# 💵 Dólar Online

Portal financeiro moderno, leve e otimizado para **GitHub Pages**, focado em cotação de moedas em tempo real e conversão.

## 🚀 Tecnologias
- **Vite** + **React** (Leve & Performático)
- **Tailwind CSS** (Design Premium/Dark Mode)
- **Motion** (Animações Fluídas)
- **AwesomeAPI** (Cotações em Tempo Real)
- **GitHub Actions** (Deploy Automático)

## 📦 Como Publicar no GitHub Pages

Este projeto já vem com um workflow do GitHub Actions configurado para deploy automático.

1.  Crie um novo repositório no seu GitHub.
2.  Suba os arquivos para a branch `main`:
    ```bash
    git init
    git add .
    git commit -m "feat: initial commit"
    git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
    git push -u origin main
    ```
3.  O GitHub Actions irá detectar o push e iniciar o processo de build e deploy automaticamente.
4.  Vá em **Settings > Pages** no seu repositório GitHub e certifique-se de que a branch de deploy está definida como `gh-pages`.
5.  Acesse seu site em `https://SEU_USUARIO.github.io/SEU_REPOSITORIO/`.

## 🛠️ Desenvolvimento Local

1.  Instale as dependências:
    ```bash
    npm install
    ```
2.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
3.  Para gerar a versão de produção:
    ```bash
    npm run build
    ```
